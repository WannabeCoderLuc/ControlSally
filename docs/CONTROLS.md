# Controls

Keyboard (the game window must be in front). Movement is relative to the camera.

| Key | Action |
|---|---|
| Numpad 8 / 2 / 4 / 6 | Move forward / back / left / right |
| Numpad 5 | Hold position |
| Numpad 0 | Release to the AI (any move key takes control back) |
| Numpad + | Jump 40 m ahead |
| Numpad 7 | Sword |
| Numpad 9 (hold) | Gatling |
| Numpad 1 (hold) | Flamethrower |
| Numpad . | Missiles |
| Numpad 3 | Grenade launcher |
| Numpad − | Stomp |
| PageUp | Sword 2 |
| Numpad / | Cycle eye colour |
| F6 / F7 / F8 / F9 | Eyes red / blue / rainbow / white |
| Insert | Toggle combat phase lock |
| Delete | Toggle idle hold (experimental: the mech stops walking) |
| Numpad * | Mark (log entry) |
| Ctrl + Shift + End | Panic: release control and stop the driver |

Weapons aim at the point the camera looks at (about 60 m ahead).

Driver options: `python sally_pilot.py --help` (session length, step distance, aim distance, start eye colour, phase).
